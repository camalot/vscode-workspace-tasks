{: .important }
As of `v1.5.0`, Queues have been renamed to Compound Tasks to align with Visual Studio Code's terminology. The main feature remains the same, but now they can be executed sequentially or in parallel. You may see "Compound Task (Queue)" in some UI elements and documentation for clarity during the transition. VSCode Compound Tasks are referenced as "VSCode Compound Tasks" to differentiate from Workspace Tasks' Queues.
